## 🚀 Автоматическая настройка проекта (Быстрый старт)

Этот репозиторий спроектирован как **GitHub Template**. Нажмите кнопку **"Use this template"** выше, чтобы создать копию архитектуры в своём профиле.

После клонирования проекта, чтобы не менять структуру пакетов вручную во всех модулях, запустите готовый скрипт автоматизации прямо во встроенном **Terminal** Android Studio:

```bash
py init_project.py com.architecturetemplate
```

### Что сделает скрипт:
1. Автоматически заменит все упоминания базового пакета в `build.gradle.kts`, `AndroidManifest.xml` и Kotlin-файлах.
2. Перестроит физическую структуру папок на диске (поддерживает директории `java` и `kotlin`).
3. Защитит ваши кастомные Gradle Convention Plugins и дизайн-систему (`ui.theme`) от поломки импортов.

*💡 Если вы опечатались в названии, не переживайте: скрипт защищен от ошибок. Вы можете запустить команду повторно с правильным именем, и он автоматически перепишет проект поверх прошлой опечатки. После успешной настройки проекта и нажатия кнопки **Sync Now** в Android Studio, файл `init_project.py` можно удалить из корня.*
